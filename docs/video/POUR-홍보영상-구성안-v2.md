## 3. 바꾼 것 세 가지

### ① 5가지 서비스를 포토 시퀀스로 (30.4–49.8s)

카드 나열을 없애고, 화면 중앙의 큰 프레임(1120×630) 안에 소재가 들어왔다 사라지며 다음으로
이어지는 구조로 바꿨습니다.

- 사진은 **1.0 → 1.07 스케일 인**, 전환은 0.4초 크로스 디졸브. 컷이 아니라 흐름으로 이어집니다.
- 텍스트는 프레임 안 좌하단에 **서비스명 한 줄**만. 설명은 기존 자막 바가 그대로 담당합니다.
- 5장을 같은 리듬으로 두지 않았습니다 — `4.1 / 3.2 / 3.2 / 5.0 / 4.7초`.

| # | 서비스 (원본 그대로) | 길이 | 소재 |
| --- | --- | --- | --- |
| 01 | 기술개발 · 자재생산 | 4.1s | 실사 (제품 + 공장) |
| 02 | 공법설명회 | 3.2s | 실사 (설명회 현장) |
| 03 | 현장 맞춤 기술자료 | 3.2s | 실사 (컨설팅 내역서) |
| 04 | 정확한 기술검토 빠른 현장지원 | 5.0s | **사진 없음** — 원본 항목 유지 |
| 05 | 공사 전 · 중 · 후 현장관리 | 4.7s | **사진 없음** — 원본 항목 유지 |

> 04·05는 원본 영상에도 실사가 없어(항목 리스트와 아이콘으로만 구성) 원본 내용을 그대로 두었습니다.
> 사진을 확보하면 01~03과 동일한 포토 프레임으로 바로 교체됩니다.

### ② 체결 과정 24초 → 7.7초

단계마다 화면을 갈아끼우는 방식을 버리고 **한 레이아웃 안에서 체크만 순차 점등**시켰습니다.

- 유지: `POUR와의 협력은 서로의 방향을 확인하는 것에서 시작합니다.` / `두 차례의 만남을 통해 협력의 기준이 마련되면` / `세 번째 단계로 MOU를 체결합니다.`
- 유지: 3단계 라벨(POUR 본사 미팅 · 시공사 방문 미팅 · MOU 체결), AGREEMENT 배지
- **덜어낸 자막 6줄** (단계별 세부 설명):
  `첫 번째는 POUR 본사 미팅입니다.` / `POUR의 기술 운영 방식과 현장 지원 체계를 소개하고,` /
  `협력을 위한 기본 방향을 함께 정리합니다.` / `두 번째는 시공사 방문 미팅입니다.` /
  `POUR가 직접 방문해 시공사의 주요 사업과 현장 운영 방향을 듣고` /
  `POUR 공법의 적용 방식과 지원 내용을 구체적으로 설명합니다.`
- 세부 협의 항목(기술 운영 방식 / 현장 지원 방향 / 주요 사업 / 지원 내용)도 화면에서 제외했습니다.

> 문구를 고친 것이 아니라 **덜어낸 것**입니다. 되살릴 줄은 위 6줄이 전부입니다.

### ③ 지원 체계의 근거와 결론을 붙였다

`60명 전문 인력 / 이것이 POUR의 지원 체계입니다.`를 **5가지 서비스 바로 뒤(50.2s)** 로 옮겨,
다섯 가지를 보여준 직후에 "이것이 지원 체계다"로 닫히게 했습니다. 원본에서는 서비스와 결론
사이에 거리가 있었습니다.

## 4. 바꾸지 않은 것

- **자막 45줄 전부 원문 그대로.** 새로 쓴 문장 없음, 어미·조사·문장부호까지 동일.
- **장면 구성요소 전부 유지** — 더 나은 현장 / 새로운 기회 / 시장 경쟁력, PROCESS 4단계,
  2,600,000 세대, 현장 진단 4항목, 경험·데이터 → 현장 분석 → 적합한 적용 방향,
  SUPPORT 01–05 제목과 항목, 60명, 협력 프로세스 3단계, 선택→적용→수주→실적,
  더 많이 수주 → 더 많은 실적, 엔딩 카피와 연락처.
- **서비스 순서도 원본 그대로** (01 기술개발·자재생산 → 05 공사 전·중·후 현장관리).

## 5. 남은 작업

1. **SUPPORT 04 · 05용 실사 확보.** 이 둘만 사진이 들어가면 다섯 장면이 완전한 포토 시퀀스가 됩니다.
2. **원본 사진 파일.** 현재 01–03 사진은 기존 영상(1.3Mbps)에서 추출해 다소 뭉개져 있습니다.
   원본 파일로 교체하면 선명도가 올라갑니다.
3. 덜어낸 체결 자막 6줄 중 되살릴 것이 있는지 확인.
