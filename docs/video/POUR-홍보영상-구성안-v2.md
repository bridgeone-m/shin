### 핵심 문제
1. **체결 과정(24초)이 서비스(18초)보다 길다.** 영상에서 가장 긴 블록이 "만나서 서명하는 절차"다. 체결은 주인공이 아니다.
2. **서비스가 나열이다.** `SUPPORT 01~05`가 같은 레이아웃으로 5번 반복되어 "항목"으로 읽히고 "경쟁력"으로 읽히지 않는다.
3. **메시지가 자기소개형이다.** "POUR는 ~합니다"가 반복될 뿐, "그래서 시공사가 얻는 것"이 문장으로 박히지 않는다.
4. 중간(54–62s)에 등장하는 `60명 전문인력 / 통합 지원 체계`가 영상의 가장 강한 주장인데, 이미 템포가 떨어진 뒤에 나온다.

## 3. 블록별 상세

### A. 문제 제기 + 차별점 선언 (0–8s)

기존 "새로운 공법을 찾는 이유" 3줄은 유지하되, **마지막 한 줄을 교체**해 질문을 던진다.

| 시간 | 화면 | 자막 |
| --- | --- | --- |
| 0.0–2.0s | 화이트 배경, 좌측 라인 타이포 1행 | `│ 더 나은 현장` / 하단: 시공사가 새로운 공법을 찾는 이유는 분명합니다. |
| 2.0–4.0s | 2행 추가 | `│ 새로운 기회` / 하단: 새로운 기회를 준비하고, |
| 4.0–6.0s | 3행 추가 | `│ 시장 경쟁력` / 하단: 시장에서 경쟁력을 갖추기 위해서입니다. |
| 6.0–8.0s | 3행 페이드 아웃 → 한 문장만 남김 (네이비 전환) | **공법은 많습니다.<br>끝까지 함께 가는 곳은 많지 않습니다.** |

- 6초 지점의 화이트→네이비 전환이 영상 전체의 첫 번째 임팩트 포인트.
- 기존 9s → 8s.

### B. POUR만의 지원 체계 (8–18s)

기존 54–62s에 있던 `60명 / 통합 지원 체계`를 **앞으로 끌어온다.** 서비스 나열 전에 "왜 이게 가능한가"의 근거를 먼저 세운다.

| 시간 | 화면 | 자막 |
| --- | --- | --- |
| 8–11s | 네이비, 숫자 카운트업 `2,600,000` | 260만 세대의 현장에서 쌓은 데이터와 |
| 11–14s | 숫자 교체 카운트업 `60` | 60명의 전문 인력이 |
| 14–18s | 두 숫자가 좌우로 축소 정렬 → 중앙에 배지 등장<br>`POUR 통합 지원 체계` | **공법 하나가 아니라, 지원 체계 전체를 제공합니다.** |

- 두 숫자를 **한 화면에 수렴**시키는 모션이 핵심. 따로 보여주면 다시 나열이 된다.
- 기존 21–35s(14s)의 260만 블록과 54–62s(9s)의 60명 블록 = 23초를 10초로 통합.

### C. 5가지 서비스 포토 시퀀스 (18–37s / 19초) ★ 핵심

**구성 원칙**
- 다이어그램·카드 레이아웃 금지. **실사 사진이 화면의 주인공.**
- 5장을 같은 리듬으로 나열하지 않는다. `도입 1장(길게) → 중간 3장(빠르게) → 마지막 1장(길게, 엔딩 연결)`의 호흡.
- 텍스트는 **서비스명 1줄 + 혜택 1줄**, 최대 12자 내외. 사진을 가리지 않게 좌하단 또는 우하단 고정.
- 전환은 사진이 **살짝 스케일 인(1.0→1.06) 하면서 크로스 디졸브**. 컷 전환이 아니라 흐름으로 이어지게.

### E. 체결 과정 (47–55s / 8초) ★ 대폭 압축

**24초 → 8초.** 단계별 세부 항목(기술 운영 방식 / 현장 지원 체계 / 협력 방향 / 주요 사업 / 현장 운영 방향 …)은 **전부 삭제**한다. 체결은 "어렵지 않다"만 전달하면 된다.

| 시간 | 화면 | 자막 |
| --- | --- | --- |
| 47–48s | 섹션 타이틀 `COOPERATION PROCESS` | 협력은 간단합니다. |
| 48–53s | **한 화면에 3단계 타임라인 유지**, 체크 표시만 1.5초 간격으로 순차 점등<br>`01 POUR 본사 미팅 ✓ → 02 시공사 방문 미팅 ✓ → 03 MOU 체결 ✓` | 두 번의 만남, 한 번의 체결. |
| 53–55s | MOU 배지 강조 `POUR 공법 특허 사용 MOU 체결` | **그 다음부터는 POUR가 함께 움직입니다.** |

- 화면 전환 없이 **한 레이아웃 안에서 체크만 찍히게** 한다. 단계별로 화면을 갈아끼우기 때문에 길어지는 것.
- 세부 협의 항목은 영상이 아니라 제안서·상담에서 다룰 내용.

### F. 시공사의 경쟁력으로 연결 (55–70s)

영상의 결론부. "POUR가 한 일"이 아니라 **"시공사가 얻은 것"**의 문장으로 쓴다.

| 시간 | 화면 | 자막 |
| --- | --- | --- |
| 55–58s | 네이비, `선택 → 적용 → 수주 → 실적` 좌→우 생성 | 좋은 공법의 기준은 결국 현장에서 이기는 것. |
| 58–62s | 상단으로 축소 이동 → 하단에 우상향 그래프 | 선택되고, 적용되고, |
| 62–66s | 강조 박스 2단 `더 많이 수주` → `더 많은 실적` | 수주와 실적으로 이어져야 합니다. |
| 66–70s | 그래프 끝점에서 빛 번짐 → 전체 화이트 아웃 | **공법사를 바꾸면, 영업이 달라집니다.** |

- 66s의 카피가 영상 전체의 결론 문장. 기존 영상에는 이 한 방이 없다.
